# Harmonia v3 (recherche) — de vrais presets, un moteur à 45 paramètres et un mode DX7

Branche de recherche `research/ai-v3-presets` : elle ne sera pas mergée. Toutes les données d'entraînement viennent de vrais presets conçus par des humains ou de vrais enregistrements, jamais de données générées.

## Banques utilisées

| Banque | Presets uniques | Licence | Contenu |
|---|---|---|---|
| DX7 (Dexed : cartouches Yamaha d'origine + collections) | 27 471 (sur 105 274 voix) | collection communautaire, non précisée | pianos électriques, cuivres, orgues, cloches… et de nombreux noms de sons célèbres |
| Surge XT (usine + tiers) | 3 555 | GPL-3 | catégories, auteurs, commentaires |
| OB-Xf (style Oberheim OB-X) | 492 | CC0 | catégories |

Les fichiers d'origine ne sont pas redistribués : `scripts/v3/fetch_presets.py` les télécharge depuis leur source (commit ou sha256 épinglé) dans `~/Datasets/harmonia-presets`, et `scripts/v3/presets_to_json.py` les convertit en JSON (un preset par ligne, doublons fusionnés en gardant tous les noms).

## Ce que les vrais presets utilisent (`scripts/v3/analyze_presets.py`)

| Fonction | OB-Xf | Surge |
|---|---|---|
| 2e oscillateur | 85 % | 50 % |
| Intervalle entre oscillateurs | 72 % | – |
| Pulse / modulation de largeur | 66 % / 46 % | – |
| FM entre oscillateurs | 66 % | 27 % |
| Unisson | 63 % | 42 % |
| Filtre 24 dB | 55 % | 54 % |
| Suivi de clavier du filtre | 75 % | 48 % |
| Enveloppe de filtre avec attaque / sustain | 43 % / 42 % | 24 % / 24 % |
| Reverb / delay / chorus | – | 52 / 48 / 17 % |

94 % des voix DX7 utilisent 5 ou 6 opérateurs : une FM réduite ne les rejoue pas.

## Moteur classique v3 (`src/synth/engine_v3.py`, `src/synth/v3_params.py`)

45 paramètres : les 20 de la v2 + intervalle de chaque oscillateur, largeur d'impulsion, sync, FM (osc2 → osc1), ring mod, unisson (voix, désaccord), pente 12/24 dB, suivi de clavier, enveloppe de filtre complète, vélocité → volume, enveloppe de pitch, forme / délai du LFO, LFO → volume et → largeur d'impulsion, chorus, delay (temps, retour, mix), taille de reverb.

Améliorations de qualité : dents de scie et carrés sans repliement (PolyBLEP), decays et releases exponentiels comme sur un synthé analogique, enveloppes et LFO plus amples (OB-Xf va jusqu'à 9 octaves d'enveloppe de filtre). Un preset v2 garde son son à ces corrections près (0,1 % d'écart en sinus).

## Mode DX7 (`native/dx7`)

Le cœur FM de Dexed (msfa, Google, licence Apache 2.0) joue les voix DX7 telles quelles : pas de conversion, pas de perte. Le même code C++ peut être intégré à l'app. Le moteur « Mark I » de Dexed (GPL-3) n'est pas utilisé.

## Conversion et vérification à l'oreille (`src/presets/convert_*.py`, `src/presets/matching.py`)

1. Chaque preset OB-Xf / Surge est joué dans son synthé d'origine (plugin officiel via pedalboard) sur do2, do3, do4.
2. Ses paramètres sont traduits vers Harmonia avec les vraies courbes du synthé (lues dans son code source).
3. Un optimiseur (CMA-ES) corrige les paramètres continus pour rapprocher les spectrogrammes (écart moyen en dB, volume égalisé).

Repères : un preset au hasard est à 33–49 dB de l'original.

## Commandes

```bash
python scripts/v3/fetch_presets.py              # banques + sources msfa
python scripts/v3/presets_to_json.py            # -> data/v3/presets/*.jsonl
python scripts/v3/analyze_presets.py            # usage des fonctions
python scripts/v3/build_dx7.py                  # compile le rendu DX7
python scripts/v3/match_presets.py --source obxf --workers 10
python scripts/v3/match_presets.py --source surge --workers 10
python scripts/v3/listening_v3.py               # page d'écoute avec notation
```
