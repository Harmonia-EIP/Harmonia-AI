# Welcome to Hamonia-AI

**Hamonia-AI** is a lightweight generative engine that turns human text descriptions (e.g., *"Dark cinematic drone"*) into synthesizer presets for JUCE audio plugins.

## 🚀 Key Features

* **Text-to-Param:** Semantic understanding of sound descriptions.
* **Lightweight:** Runs on standard CPUs (no GPU required for inference).
* **Real-time:** Generates presets in milliseconds.
* **Architecture:** BERT-based Encoder + Neural Network Parameter Head.

## 📥 Installation

```bash
git clone [https://github.com/your-repo/Text2JUCE-AI](https://github.com/your-repo/Text2JUCE-AI)
pip install -r requirements.txt
```
