Mêmes prompts, trois IA : écoutez la différence

Chaque son est le preset généré pour le prompt, joué sur un La3 (220 Hz) pendant 1,5 s puis relâché, avec le moteur exact de l'app. Le chiffre à côté de chaque prise est la note d'un juge indépendant (Microsoft CLAP) entre le son et la description : plus il est haut, plus le son correspond au texte.

  • La même IA v1 avec le prompt en anglais (son meilleur cas)
  • Harmonia v2 avec le prompt français, sur l'app corrigée

Comment ces sons ont été produits

Le moteur de rendu est un portage Python du code C++ de l'app (oscillateurs, filtre, enveloppes, distorsion, reverb), vérifié échantillon par échantillon contre le vrai Synth.cpp compilé avec JUCE. La v1 est jouée sur l'app actuelle ; la v2 sur l'app avec les deux corrections du filtre et des enveloppes.

Les prompts de ce banc d'écoute ont été retirés de toutes les données d'entraînement. Le juge n'a servi ni à entraîner ni à régler le modèle.
